## ⚠️ الخطوة المعلَّقة: الدخول برقم الجوال (OTP)

**هذه لا تُنفَّذ بالشيفرة ولا من هذه الجلسة.** تحتاج حسابًا لدى مزوّد رسائل
ومفاتيحه، وكلاهما بيد المالك.

والمخطّط يعتمد الجوال هويةً: `profiles.phone` فريد، والتسجيل المتوقَّع بـOTP.
وحتى تُفعَّل، **الدخول بالبريد يعمل** ويكفي للتطوير والاختبار.

### الطريق السريع — Twilio

لوحة Supabase ← **Authentication ← Sign In / Providers ← Phone** ← تفعيل، ثم
اختيار Twilio وإدخال:

```
Twilio Account SID
Twilio Auth Token
Twilio Message Service SID
```

يعمل فورًا، وتسليمه إلى الأرقام السعودية مقبول، لكن كلفته بالرسالة أعلى من
المزوّد المحلّي.

### الطريق الموصى به للسوق السعودي — مزوّد محلّي عبر Send SMS Hook

مزوّدو الرسائل المحلّيون (Unifonic، مسجات، تقنيات) أرخص، وأهمّ من ذلك أنّ
**اسم المرسِل (Sender ID) العربيّ المسجَّل لدى هيئة الاتصالات** يرفع نسبة
التسليم كثيرًا — والرسالة التي لا تصل تُسقط التسجيل كلّه.

وSupabase لا يدعمهم أصلًا، لكنه يسمح باعتراض إرسال الرسالة عبر **Send SMS
Hook**: دالّة Edge تستقبل الرقم والرمز وترسلهما بمزوّدك.

```
Authentication ← Hooks ← Send SMS hook ← اختر دالّة Edge
```

والدالّة تُنشر في `supabase/functions/send-sms/`، ومفتاح المزوّد في
**Edge Functions ← Secrets** لا في المستودع.

> **ترتيب مقترح**: فعّل Twilio أوّلًا لتتحرّك التجربة، ثم انقل إلى المحلّي قبل
> الإطلاق. النقل تغييرُ إعدادٍ لا شيفرة، لأن التطبيق ينادي
> `signInWithOtp(phone:)` في الحالتين ولا يعرف من يرسل.

### وبعد التفعيل

- **الحدّ من المحاولات**: Authentication ← Rate Limits. بلا حدٍّ يستنزف أحدهم
  رصيد الرسائل في ساعة.
- **مدّة صلاحية الرمز**: دقائق لا ساعات.
- **اختبار على رقمٍ سعوديّ حقيقي**: صيغة `+9665XXXXXXXX`. والمحاكي لا يكفي.

## إعدادات لازمة أخرى

| الإعداد | الموضع | السبب |
|---|---|---|
| **Storage buckets** | Storage | صور القطع وإثبات التسليم والتوقيع |
| **حدّ حجم الرفع** | Storage ← Settings | صورةٌ بلا ضغط تبتلع السقف |
| **Realtime** | Database ← Replication | تتبّع الطلب لحظيًّا |
| **النسخ الاحتياطي** | Database ← Backups | الخطة المجانية تحتفظ بمدّة قصيرة |

## قيدُ تخزينٍ يجب التخطيط له

وصل تطبيقٌ **كثيف الصور** بطبيعته: صور القطع عند الفحص، وإثبات الاستلام،
وإثبات التسليم، والتوقيع. وسقف التخزين في الخطة المجانية محدود.

فالصور تُضغط وتُصغَّر **في التطبيق قبل الرفع** لا بعده، ويُراقَب السقف. وحين
يقترب: إمّا ترقية، أو نقل الصور إلى تخزينٍ آخر.
